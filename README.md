<p><b>Independent open-source software.</b><br>

---

KuchiSofts builds free, open-source software: media apps for Windows, Linux, macOS and Android, privacy tools,
browser extensions and small utilities that make everyday apps nicer to use. Every project is designed to be
private by default, with no ads, no telemetry and no account required.

## Principles

- **Private by default.** No telemetry, no ads, no accounts.
- **Open source.** Every project is free software you can read, build and change.
- **Finished, not just working.** Real installers, updates, documentation and translations.
